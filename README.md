# MERN E-Commerce Website

A full-stack e-commerce web application developed as a personal project to gain hands-on experience with the MERN stack and understand real-world application development.

## Features

- **User Authentication:** Registration and login functionality.
- **Product Management:** Browse products and view product details.
- **Shopping Cart:** Add, remove, and manage cart items.
- **Order Management:** Place orders and manage order information.
- **Secure Payment Integration:** Backend payment verification for reliable payment processing.
- **Admin Dashboard:** Manage products, inventory, and customer orders.
- **Cloudinary Integration:** Upload and manage product images.
- **Responsive UI:** User-friendly interface built with React.

## Tech Stack

- **Frontend:** React.js, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** JWT
- **Payments:** Stripe
- **Image Storage:** Cloudinary
- **Deployment:** Vercel, Render
- **Version Control:** Git, GitHub

## Key Learnings

- Built a full-stack application using the MERN stack.
- Developed REST APIs and integrated frontend and backend services.
- Implemented authentication and protected routes.
- Integrated third-party services for payments and image storage.
- Learned to verify payments on the backend instead of relying solely on frontend confirmation.
- Deployed application components and managed environment variables.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Vigneshvicky13/ecommerce-app
cd ecommerce-app
```

### 2. Install dependencies

Install dependencies in the frontend and backend directories:

```bash
cd frontend
npm install
```

```bash
cd ../backend
npm install
```

### 3. Configure environment variables

Create the required `.env` files and configure your MongoDB connection, JWT secret, Cloudinary credentials, Stripe keys, and API URLs.

Never commit secrets or API keys to GitHub.

### 4. Run the application

Start the frontend and backend using the development scripts defined in their respective `package.json` files.
